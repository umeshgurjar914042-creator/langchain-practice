# LangChain Practice

Part of my Generative AI Engineer learning journey.

## What I practiced
- Text splitting with RecursiveCharacterTextSplitter (chunk size and overlap)
- Reusable prompts with ChatPromptTemplate

## What I learned
- A smaller chunk_size creates more chunks; overlap keeps context from getting cut
- Prompt templates make the RAG prompt reusable and easier to change
